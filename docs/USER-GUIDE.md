# wText 기능 설명서

## 시작하기와 도움말

wText는 Windows x64용 무료 텍스트 편집기입니다. 문서 탭, 작업 폴더 탐색, 구문 강조, 파일·텍스트 비교를 제공합니다.

- 새 문서: Ctrl+N. 바로 본문에 입력할 수 있습니다.
- 파일 열기: Ctrl+O. 파일을 창에 끌어 놓거나 실행 인자로 전달해도 됩니다.
- 저장: Ctrl+S. 새 문서는 저장할 위치를 선택합니다.
- 기능 설명서: 도움말 → 기능 설명서 또는 F1. 편집기·검색창·비교창·설정창에서도 열 수 있습니다.

왼쪽 목차에서 주제를 선택하세요. 위 검색란은 제목과 본문을 검색해 관련 주제를 표시합니다. 공백으로 구분한 검색어는 모두 포함하는 주제를 찾습니다. Ctrl+F는 설명서 검색란으로 이동하고, 검색 지우기는 전체 목차를 복원합니다. 본문은 선택해서 Ctrl+C로 복사할 수 있습니다. Esc 또는 닫기로 설명서를 닫습니다. F1을 반복해도 같은 창에서는 설명서 창이 중복되지 않습니다.

설명서는 앱에 포함되어 인터넷 연결이 필요 없습니다. 앱 버전은 설명서 하단과 도움말 → wText 정보에서 확인합니다.

## 파일 열기·저장과 인코딩

파일 메뉴에서 새 문서, 파일 열기, 저장, 다른 이름으로 저장, 파일 다시 불러오기, UTF-8로 변환, 탭 닫기, 끝내기를 실행합니다.

- Ctrl+Shift+S: 다른 이름으로 저장. 편집 내용을 별도 경로에 보존할 때 사용합니다.
- UTF-8, BOM이 있는 UTF-16/32를 인식합니다. UTF-8로 읽을 수 없는 파일은 확인 후 CP949로 열 수 있습니다.
- 원본 인코딩과 CRLF/LF/CR 줄바꿈을 보존합니다. 상태 표시줄에서 인코딩과 줄바꿈 형식을 확인합니다.
- 현재 인코딩으로 표현할 수 없는 문자가 있으면 저장을 막고 안내합니다. 파일 → UTF-8로 변환 후 저장할 수 있습니다.
- 저장은 외부 변경을 확인하고 임시 파일을 통해 원본을 교체합니다. 다른 프로그램이 바꾼 원본을 조용히 덮어쓰지 않습니다.

파일 열기·저장은 16 MiB까지 지원합니다. 지원하지 않는 파일이나 읽기·쓰기 실패는 안내하며, 오류 대화상자의 자세한 내용에서 상세 정보를 확인하고 복사할 수 있습니다.

## 문서 탭과 작업 화면

여러 파일을 탭으로 열며 왼쪽 열린 문서 목록에서도 전환합니다. 탭 이름의 ●는 원본 파일에 아직 저장하지 않은 변경을 나타냅니다.

- Ctrl+Tab / Ctrl+Shift+Tab: 다음 / 이전 문서.
- Ctrl+W 또는 탭의 ×: 현재 문서 닫기. 미저장 변경이 있으면 저장 여부를 확인합니다.
- Ctrl+B 또는 좌측 상단 버튼: 사이드바 표시 / 숨김.
- 사이드바 경계 드래그: 너비 변경. 열린 문서와 탐색기를 각각 접을 수도 있습니다.
- F11: 집중 모드. Esc 또는 집중 모드 나가기 버튼으로 돌아갑니다.

상태 표시줄은 커서의 Ln(줄)·Col(열), 인코딩·줄바꿈, 언어, 글자 크기를 표시합니다. 언어와 글자 크기를 눌러 변경할 수 있습니다. 집중 모드는 임시 상태이며 사이드바 설정은 저장됩니다.

## 기본 편집과 줄 편집

텍스트를 선택한 뒤 Ctrl+C로 복사, Ctrl+X로 잘라내기, Ctrl+V로 붙여넣기합니다. 편집 메뉴에서도 같은 동작을 실행합니다. Ctrl+A는 전체 선택, Ctrl+Z는 실행 취소, Ctrl+Y는 다시 실행입니다. Tab / Shift+Tab은 들여쓰기 / 내어쓰기입니다.

- Ctrl+L: 현재 줄 또는 선택에 걸친 줄 전체 선택.
- Ctrl+Alt+D: 선택 내용 복제. 선택이 없으면 현재 줄을 다음 줄에 복제합니다.
- Ctrl+Shift+↑ / Ctrl+Shift+↓: 현재 줄 또는 선택한 줄을 위 / 아래로 이동.
- Ctrl+Shift+K: 현재 줄 또는 선택한 줄 삭제.

여러 줄 선택의 끝이 다음 줄 시작에 정확히 닿으면 그 다음 줄은 이동·삭제 대상에서 제외합니다. 줄 편집은 기존 줄바꿈을 보존하고 Ctrl+Z 한 번으로 취소할 수 있습니다. 직사각형 선택 중에는 위의 선형 줄 명령이 비활성화됩니다. 일반 클릭으로 선택을 해제한 뒤 사용하세요.

새 블록·줄 명령은 검색 결과 동시 편집을 종료하고 현재 문서에 적용합니다. 본문 전용 단축키는 검색 입력란이나 탐색기의 단축키와 구분됩니다.

## 직사각형 블록 선택·복사·붙여넣기

블록 선택은 여러 줄에서 같은 화면 열 범위를 선택합니다. Alt+마우스 왼쪽 드래그 또는 Alt+Shift+방향키를 사용하세요. 일반 선택 후 Ctrl+Alt+B 또는 편집 → 선택 영역을 직사각형 블록으로를 누르면 양 끝을 기준으로 바뀝니다. 키보드만 사용하려면 Shift+방향키로 범위를 선택하고 Ctrl+Alt+B로 직사각형으로 바꾼 뒤 Ctrl+C로 복사하세요. 선택이 없으면 현재 커서에서 블록 선택을 시작하며 Alt+Shift+방향키로 확장할 수 있습니다.

- Ctrl+Shift+C: 블록 복사. 일반 선택이 있으면 직사각형으로 바꿔 복사합니다.
- Ctrl+C / Ctrl+X: 선택한 직사각형 블록 복사 / 잘라내기.
- Ctrl+Shift+V: 외부 텍스트도 블록 형태로 붙여넣기.
- Ctrl+V: 블록 형식을 가진 클립보드이거나 현재 직사각형을 선택한 경우 블록 붙여넣기.
- 선택한 블록에 입력하거나 Delete를 누르면 여러 줄에 적용됩니다.

예: 세 줄의 11, 22, 33을 복사하고 다른 문서의 같은 열에 붙이면 각각의 줄에 들어갑니다. 짧은 줄은 공백으로 채우고 문서 끝을 넘으면 기존 줄바꿈 형식으로 필요한 줄을 만듭니다. 빈 첫 행도 유지합니다.

선택한 블록을 교체할 때 한 줄은 모든 선택 줄에 반복됩니다. 여러 줄은 선택한 줄 수와 같아야 하며 다르면 원문을 유지하고 안내합니다. 일반 선택이 남아 있으면 선택을 해제하거나 직사각형으로 바꿔 주세요. 붙여넣기는 Ctrl+Z 한 번으로 되돌립니다.

블록은 글자의 화면 위치를 기준으로 합니다. 탭·한글·비례폭 글꼴·자동 줄바꿈은 화면 열에 영향을 줄 수 있으므로 정밀 열 작업에는 고정폭 글꼴을 사용하고 자동 줄바꿈을 끄는 편이 좋습니다. 여러 불연속 블록이나 임의 위치 다중 커서는 지원하지 않습니다.

## 미니맵과 문서 탐색

오른쪽 미니맵은 문서 전체의 형태를 보여 줍니다. 음영 사각형은 현재 보이는 화면 범위이고 주황색 선은 입력 커서 위치입니다.

- 클릭 / 드래그: 해당 줄 부근으로 화면을 이동합니다. 입력 커서와 선택 영역은 유지합니다.
- 미니맵 위 마우스 휠: 본문 스크롤.
- 보기 → 미니맵 표시: 바로 켜기 / 끄기.
- 보기 → 글꼴 및 편집 설정 → 우측 미니맵 표시: 설정에서 켜기 / 끄기.

기본값은 켜짐입니다. 열린 문서 전체와 새 문서에 적용하고 다음 실행에도 유지합니다. 비교창에는 미니맵을 표시하지 않습니다. 긴 문서는 일부 줄과 각 줄 앞부분을 표본으로 표시하며 구문 강조 색상은 표시하지 않습니다.

## 찾기·바꾸기

Ctrl+F 또는 편집 → 찾기로 검색란을 엽니다. 본문에서 한 줄을 선택했다면 검색어로 채우고 입력란으로 포커스를 옮깁니다. Ctrl+H는 바꾸기 입력란도 표시합니다.

- 대소문자 옵션으로 구분 여부를 선택합니다.
- 모든 일치 항목을 강조하며 결과 개수와 현재 위치를 표시합니다.
- F3 / Shift+F3 또는 다음 찾기 / 이전 찾기로 순환 이동합니다.
- 찾을 내용 입력란에서는 Enter / Shift+Enter로 다음 / 이전 결과에 갑니다.
- 바꾸기는 현재 항목, 모두 바꾸기는 문서 전체에 적용합니다. 모두 바꾸기는 Ctrl+Z 한 번으로 취소합니다.
- Esc 또는 닫기로 검색을 닫습니다. 바꾸기 표시/숨기기 버튼으로 입력란을 접을 수 있습니다.

빈 검색어는 편집하지 않습니다. 검색은 일반 문자열이며 정규식과 작업 폴더 전체 내용 검색은 지원하지 않습니다.

## 검색 결과 동시 편집

Ctrl+F로 문자열을 찾은 뒤 검색 결과 동시 편집을 켜세요. 체크한 시점의 모든 결과가 함께 편집됩니다. 예를 들어 name = name; print(name);에서 name을 찾고 value를 입력하면 세 곳 모두 바뀝니다.

- 연속 입력, 붙여넣기, 잘라내기, Backspace/Delete, Enter, Tab을 함께 적용합니다.
- 각 결과 내부에서 커서를 움직이거나 일부만 선택해 바꿀 수 있습니다.
- 입력한 텍스트에 검색어가 있어도 대상이 새로 늘어나지 않습니다.
- Ctrl+Z는 마지막 입력을 모든 대상에서 함께 취소하고 동시 편집을 종료합니다.
- Esc 또는 체크 해제로 일반 편집에 돌아갑니다.

검색어·대소문자 변경, 탭 전환, 검색 닫기, 일반 바꾸기, 문서 정렬·줄 편집 등 다른 편집 명령을 사용하면 종료합니다. 대상 밖 입력이나 Ctrl/Shift를 조합한 단어·행 삭제도 일반 편집으로 전환합니다. 삭제는 검색 대상 경계를 넘어 주변 텍스트를 지우지 않습니다.

## 작업 폴더와 탐색기

Ctrl+Shift+O, 파일 → 작업 폴더 추가, 또는 폴더 드롭으로 최대 10개 작업 폴더를 엽니다. 같은 경로는 중복하지 않으며 폴더 닫기는 파일이나 열린 문서를 삭제하지 않습니다.

- 화살표로 항목 이동, Enter 또는 더블 클릭으로 파일 열기.
- Ctrl+P: 모든 작업 폴더의 파일 이름·상대 경로 검색. src editor처럼 공백으로 검색어를 조합하고 폴더 이름으로 좁힐 수 있습니다.
- Ctrl+Shift+E: 탐색기에서 현재 문서 찾기.
- 툴바: 새 파일, 새 폴더, 새로고침, 모두 접기, 현재 문서 찾기.
- F2: 이름 변경. 열린 파일 경로도 바꾸고 미저장 내용·실행 취소를 유지합니다.
- F5: 새로고침. 외부 파일 변경도 자동 반영합니다.
- 우클릭: 이름 변경, 상대·전체 경로 복사, Windows 탐색기에서 보기.
- 탐색기에 포커스가 있을 때 Ctrl+Shift+C는 전체 경로 복사입니다. 본문에서는 블록 복사입니다.

작업 폴더 행의 화살표로 접고 ×로 닫습니다. 우클릭 → 목록에서 위로 / 아래로로 순서를 바꿉니다. ··· 메뉴에는 모든 작업 폴더 닫기, 최근 작업 폴더 10개 다시 열기, 최근 폴더 기록 지우기가 있습니다.

.git, node_modules, bin, obj와 숨김 항목은 기본적으로 제외하며 ··· 메뉴에서 표시할 수 있습니다. 폴더 목록·순서·펼침·필터를 복원합니다. 연결 폴더는 자동 순회하지 않습니다. 폴더당 10,000개 항목, 검색 전체 100,000개 항목·결과 200개 한도가 있으며 한도 안내가 나오면 검색어를 좁히세요. 검색은 파일 이름·경로 대상입니다.

## 언어와 자동 정렬·들여쓰기

파일 확장자로 언어를 감지합니다. 언어 메뉴 또는 상태 표시줄에서 직접 선택하거나 자동 감지로 돌아갈 수 있습니다. 새 문서도 저장 전에 지정할 수 있습니다.

구문 강조: YAML, HTML, JavaScript, TypeScript, JSP, Java, JSON, XML, CSS, C#, C/C++, Python, SQL, PowerShell, Shell, INI/TOML/Properties, Markdown, PHP, 일반 텍스트. 어휘 기반 강조이며 자동 완성·컴파일 오류 검사는 제공하지 않습니다.

Ctrl+Shift+F 또는 보기 → 문서 자동 정렬은 지원하는 문서를 정렬합니다. JSON·JSONC·JavaScript·TypeScript·JSX/TSX·HTML·Vue·CSS·SCSS·Less·YAML·Markdown을 지원하며 일부 텍스트는 내용으로 형식을 추정합니다. 문법 오류나 미지원 형식은 원문을 유지하고 안내합니다. Ctrl+Z로 되돌릴 수 있습니다.

설정 → 들여쓰기에서 공통 기본값과 언어별 설정을 선택하세요.

- 이 형식에 별도 설정 사용: 공통 설정 대신 언어별 값을 저장.
- 공백 / 탭, 1~8칸 너비: Tab 입력과 지원 형식의 정렬에 적용.
- 기존 문서의 들여쓰기 감지 · 우선 적용: 기존 들여쓰기를 추정해 유지. 지정한 값으로 통일하려면 끄세요.

설정만 바꿔서는 원문을 재작성하지 않습니다. 실제 변환은 자동 정렬을 실행할 때 이루어집니다. YAML에는 공백을 사용합니다. 들여쓰기 감지는 추정이며 다른 IDE의 모든 포맷 규칙과 동일함을 보장하지 않습니다.

## 파일·텍스트 비교

Ctrl+Shift+D 또는 보기 → 파일 · 텍스트 비교로 별도 비교창을 엽니다. 텍스트 입력의 좌우 칸에 입력·붙여넣거나 파일 열기를 사용합니다. 파일과 직접 입력을 섞을 수 있고 빈 내용도 비교할 수 있습니다.

- 비교하기 또는 Ctrl+Enter: 현재 입력 비교.
- 각 칸의 붙여넣기 버튼: 그쪽 전체 내용을 클립보드로 교체. Ctrl+V는 현재 커서·선택 위치에 붙여넣기.
- 비우기: 해당 입력 비우기. 붙여넣기 버튼·비우기는 Ctrl+Z로 취소 가능.
- 파일 한 개 드롭: 놓은 쪽에 열기. 두 개 드롭: 전달된 순서대로 좌우에 열고 비교. 폴더나 세 개 이상은 받지 않습니다.
- 좌우 바꾸기: 입력 교환.

비교 결과는 추가=초록, 삭제=빨강, 수정=노랑으로 표시하고 변경 단어를 더 밝게 강조합니다. 양쪽 스크롤을 동기화하며 F7 / Shift+F7 또는 다음 / 이전 변경 버튼으로 이동합니다. 공백 무시 옵션으로 공백 차이의 취급을 바꿀 수 있습니다. 줄바꿈·파일 인코딩 차이는 별도로 안내합니다.

입력을 수정하면 이전 결과를 비활성화하므로 다시 비교하세요. 입력과 실행 취소는 입력/결과 화면 전환 시 유지합니다. 한쪽당 500,000자·20,000줄까지 비교하며 초과해도 입력은 지우지 않습니다.

비교창 수정은 원본 파일에 저장하지 않습니다. 입력은 창을 닫으면 사라지며 작업 복원·외부 파일 자동 갱신 대상이 아닙니다. 본문 미저장 내용을 비교하려면 복사해 붙여넣으세요. 비교 결과 병합은 지원하지 않습니다.

## 글꼴·표시와 설정 저장

보기 → 글꼴 및 편집 설정, Ctrl+, 또는 상태 표시줄의 글자 크기로 설정을 엽니다. 미리 보고 적용하거나 기본값으로 되돌릴 수 있습니다. 취소하면 변경을 적용하지 않습니다.

- 영문·숫자 JetBrains Mono, 한글 Noto Sans KR를 앱에 포함합니다. Windows에 글꼴을 설치하지 않습니다.
- 설치된 글꼴을 선택하고 크기는 9~48 px로 지정합니다. 기본값은 15 px입니다.
- Ctrl++ / Ctrl+-: 크기 증가 / 감소. Ctrl+0: 기본 크기. Ctrl+마우스 휠로도 조절합니다.
- 줄 번호, 자동 줄바꿈, 공백·탭 표시, 우측 미니맵을 켜거나 끕니다. 보기 메뉴에서도 변경할 수 있습니다.
- 다음 실행에서 열린 문서와 미저장 내용 이어하기: 창 종료 시 작업 보관 여부.

글꼴은 모든 문서와 비교창에 반영합니다. 비교창은 줄 정렬을 위해 자동 줄바꿈을 사용하지 않습니다. 설정 변경으로 문서 내용이나 실행 취소 기록을 지우지 않습니다.

설정은 %LocalAppData%\wText\settings.json, 작업 폴더는 settings.workspace.json에 저장합니다. 설치형과 무설치형이 같은 사용자 설정을 사용합니다. 설정 저장 실패 시 현재 화면에는 적용되더라도 다음 실행에는 유지되지 않을 수 있으므로 상태 메시지를 확인하세요.

## 종료·저장 확인과 작업 복원

기본 설정에서 창 X / 파일 → 끝내기는 탭과 미저장 내용을 보관합니다. 원본 파일에 반영하려면 Ctrl+S로 저장하세요. 개별 탭 X / Ctrl+W는 미저장 내용의 저장 여부를 확인합니다.

저장 확인창의 Y는 저장, N은 저장 안 함, C 또는 Esc는 계속 편집입니다. 확인창 ×도 취소입니다. 오류·인코딩 확인창에는 Y/N/C를 적용하지 않습니다. 저장 안 함으로 닫은 개별 탭은 다음 실행에 복원하지 않습니다.

작업 이어하기를 끄면 창 종료 때도 저장 / 저장 안 함 / 계속 편집을 선택합니다. 보관 또는 저장 실패 시 내용을 보호하기 위해 창을 유지합니다.

복구본은 %LocalAppData%\wText\sessions\에 둡니다. 입력이 멈춘 뒤 약 2초, 계속 편집 중에는 최대 10초 간격과 정상 종료 시 저장합니다. 재실행하면 탭 순서·활성 탭·커서·선택·언어·스크롤을 복원합니다. 실행 취소 기록은 복원하지 않습니다.

저장 후 수정하지 않은 파일은 재실행 시 최신 디스크 내용을 읽고 미저장 문서는 보관 내용을 유지합니다. 원본이 없어도 보관 내용으로 복구하고 안내합니다. 여러 창은 별도 보관 파일을 잠가 충돌을 피합니다. 창당 문서 256개·JSON 보관 파일 128 MiB 한도가 있으며 강제 종료 직전의 미보관 입력은 복원되지 않을 수 있습니다.

## 외부 변경·다시 불러오기와 오류 대응

다른 프로그램이 열린 파일을 수정하면 창 활성화 시 또는 활성 창에서 약 2초마다 확인합니다. 비활성 탭·작업 폴더 밖의 파일도 대상입니다. 단순 저장 시각 변경과 자체 저장은 알리지 않습니다.

- 미저장 수정이 없는 문서: 최신 파일을 반영하고 파일 이름·경로를 알립니다.
- 미저장 수정이 있는 문서: 계속 편집 / 수정 버리고 다시 불러오기 / 취소를 선택합니다.
- 계속 편집·Esc·×: 내용을 유지하고 외부 변경된 원본의 덮어쓰기를 막습니다. 다른 이름으로 저장하면 별도 파일로 보존할 수 있습니다.
- 같은 디스크 버전의 알림은 반복하지 않습니다. 나중에 반영하려면 파일 → 파일 다시 불러오기를 사용하세요.
- 삭제·이동·잠금·지원하지 않는 내용: 현재 버퍼를 유지하고 안내합니다. 접근이 복구되면 다시 확인합니다.

다시 불러오면 인코딩·줄바꿈을 새 파일에 맞추고 언어·표시 위치를 유지하지만 실행 취소 기록은 초기화합니다. 미저장 수정은 확인을 거쳐 폐기합니다. 중요한 작업은 먼저 다른 이름으로 저장하세요.

클립보드를 다른 프로그램이 점유해 복사·붙여넣기가 실패하면 다시 시도하세요. 블록 행 수 오류는 선택한 행과 붙일 행 수를 맞추거나 선택을 해제해 해결합니다. 설정·보관·파일 접근 오류는 경로·권한·잠금 상태를 확인하고 오류 상세 내용을 복사해 문의할 수 있습니다.

## 전체 단축키

### 파일과 창
- F1: 기능 설명서.
- Ctrl+N / Ctrl+O / Ctrl+S: 새 문서 / 파일 열기 / 저장.
- Ctrl+Shift+S / Ctrl+W: 다른 이름으로 저장 / 탭 닫기.
- Ctrl+Tab / Ctrl+Shift+Tab: 다음 / 이전 탭.
- Y / N / C 또는 Esc: 저장 확인창의 저장 / 저장 안 함 / 계속 편집.

### 본문 편집
- Ctrl+A / Ctrl+C / Ctrl+X / Ctrl+V: 전체 선택 / 복사 / 잘라내기 / 붙여넣기.
- Ctrl+Z / Ctrl+Y: 실행 취소 / 다시 실행.
- Tab / Shift+Tab: 들여쓰기 / 내어쓰기.
- Alt+드래그 / Alt+Shift+방향키: 직사각형 선택.
- Ctrl+Alt+B: 일반 선택을 직사각형 블록으로 변환. Ctrl+C로 복사.
- Ctrl+Shift+C / Ctrl+Shift+V: 블록 복사 / 블록 붙여넣기.
- Ctrl+L / Ctrl+Alt+D: 줄 선택 / 줄 또는 선택 복제.
- Ctrl+Shift+↑ / Ctrl+Shift+↓ / Ctrl+Shift+K: 줄 위 이동 / 아래 이동 / 삭제.
- Ctrl+D: 편집 컴포넌트의 기본 현재 줄 삭제. 선택한 여러 줄 삭제에는 Ctrl+Shift+K를 사용하세요.
- Ctrl+Shift+F: 문서 자동 정렬.
- Ctrl+Home / Ctrl+End: 문서 시작 / 끝. Shift를 함께 누르면 선택 확장.
- Ctrl+← / Ctrl+→: 단어 이동. Shift를 함께 누르면 선택 확장.
- Home / End / PageUp / PageDown: 줄 시작 / 줄 끝 / 화면 위 / 아래.
- Insert: 삽입 / 덮어쓰기 모드 전환.

### 검색과 비교
- Ctrl+F / Ctrl+H: 찾기 / 바꾸기.
- F3 / Shift+F3: 다음 / 이전 결과.
- Enter / Shift+Enter: 찾을 내용 입력란의 다음 / 이전 결과.
- Ctrl+Shift+D: 파일·텍스트 비교창.
- Ctrl+Enter: 비교창에서 비교 실행.
- F7 / Shift+F7: 비교창에서 다음 / 이전 변경.

### 탐색기와 표시
- Ctrl+Shift+O / Ctrl+P: 작업 폴더 추가 / 파일 이름·경로 검색.
- Ctrl+Shift+E: 현재 문서 위치 찾기.
- F2 / F5: 탐색기 이름 변경 / 새로고침.
- Ctrl+Shift+C: 탐색기 전체 경로 복사. 본문에서는 블록 복사.
- Ctrl+B / F11: 사이드바 전환 / 집중 모드.
- Ctrl+, / Ctrl++ / Ctrl+- / Ctrl+0: 설정 / 글자 크게 / 작게 / 기본 크기.
- Ctrl+마우스 휠: 글자 크기 조절.
- Esc: 현재 작업에 따라 동시 편집 해제, 검색 닫기, 집중 모드 나가기, 대화상자 취소.
- F4 / Esc: 설정의 글꼴·들여쓰기 선택 목록 열기 / 닫기.
- Ctrl+F / Esc (설명서): 주제 검색 / 설명서 닫기.

단축키는 포커스가 있는 화면에 따라 달라집니다. 파일 다시 불러오기, 미니맵 전환, UTF-8 변환, 언어 지정, 최근 폴더 관리 등은 해당 메뉴를 사용하세요.

## 설치·라이선스와 지원 범위

설치 파일은 현재 사용자 범위에 설치하고 시작 메뉴에 등록합니다. 설치 단계에서 바탕화면 바로가기 여부를 선택하며 재설치·업그레이드 시 유지합니다. Windows 설정의 앱 목록에서 제거할 수 있습니다. 파일 연결은 자동 변경하지 않습니다.

무설치 ZIP은 전체 압축을 푼 뒤 wText.exe를 실행하세요. .NET 런타임·기본 글꼴·포맷 도구가 포함되어 별도 설치가 필요 없습니다. 설치형과 무설치형은 사용자 설정·작업 보관 위치를 공유합니다.

도움말 → 라이선스 및 오픈소스 고지에서 자체 MIT와 구성요소의 원문을 확인합니다. 도움말 → wText 정보에는 제작자 Hyunwook Park, 앱 버전, GitHub 링크와 주소 복사가 있습니다. GitHub 프로젝트 열기는 기본 브라우저를 사용하므로 인터넷 연결이 필요합니다.

지원 범위: Windows x64, 일반 텍스트 편집, 제한 내 파일 비교. 정규식 검색, 임의 위치 다중 커서, 프로젝트 전체 본문 검색, 자동 완성, 코드 접기, 플러그인, 비교 병합은 제공하지 않습니다. 일부 형식의 구문 강조와 자동 정렬 지원 범위는 서로 다릅니다. 파일 크기·비교·탐색 한도는 각 주제에서 확인하세요. 버전별 변경·검증 상태는 배포본 CHANGELOG와 GitHub 릴리스 설명에서 확인하세요.
