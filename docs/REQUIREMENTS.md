# wText 요구사항 문서 안내

사용자 요구사항·수용 기준·변경 결정·후속 범위는 [rules/requirements.md](../rules/requirements.md)로 통합했습니다. 기존 요구사항 분석 내용도 해당 문서에 보존되어 있습니다.

새 작업지시를 받으면 [프로젝트 규칙](../rules/rules.md)을 먼저 읽고, 이어서 [누적 요구사항](../rules/requirements.md)을 읽으세요. 새 요구사항과 변경 내용은 `rules/requirements.md`에 기록합니다.

이 파일은 기존 링크를 위한 위치 안내입니다. 최신 배포·검증 결과는 [배포 안내](RELEASING.md)를 참고하세요.
